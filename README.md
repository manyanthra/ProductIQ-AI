# ProductIQ AI

AI-powered Industrial Product Intelligence Copilot built for UniHack 2026.

## Features

* AI product enrichment
* CSV & PDF input
* Validation & traceability
* Human-in-the-loop review
* Commerce-ready catalog export

## Tech Stack

* Streamlit
* Python
* Pandas
* Anthropic Claude API

## Run locally

```bash
pip install -r requirements.txt
cp .env.example .env
# Add your Anthropic API key
streamlit run app.py
```

## Sample Dataset

Use the CSV files inside the `data/` folder.
